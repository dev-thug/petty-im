# Petty 정책 문서 작성 근거와 운영 확인 사항

## 적용 범위

이번 문서는 petty.im의 소개·출시 알림·고객 문의를 대상으로 작성했다. 별도 앱의 회원·대화·결제 정책을 대신하지 않는다. 한국어 원문만 제공하며, 해외 랜딩페이지에서 여는 링크에도 한국어 문서임을 안내한다.

## 확인된 정보

- 운영자·대표자·사업자등록번호·사업장 주소: 사용자가 제공한 사업자등록증. 생년월일·원본 PDF는 저장소에 추가하지 않았다.
- 고객 문의 주소: 사용자 지정 support@specify.app.
- 출시 알림 DB: 사용자 확인 AWS ap-northeast-2(대한민국 서울).
- 애플리케이션 수집: 이메일·신청 일시, 요청 제한용 IP 메모리 처리, 언어 설정 쿠키(최대 1년).
- specify.app의 MX: mx.zoho.com, mx2.zoho.com, mx3.zoho.com.

## 운영에서 확인할 사항

1. Zoho 미국 보관은 .com MX와 Zoho 공식 데이터센터 안내에서 추론했다. 실제 관리자 콘솔의 데이터센터와 계약 수탁 법인·재위탁 내역을 확인하고 다르면 방침 4항을 수정한다. `support` 메일함/별칭 존재와 실제 수신은 이번 작업에서 확인하지 않았다.
2. 호스팅·프록시의 별도 접속 로그, 백업 위치·보관 주기, 외부 운영 지원 접근은 소스만으로 확인할 수 없다. 실제 배포 인프라와 방침을 대조한다. README에는 Vercel 배포가 안내되어 있으나 실제 이용 여부는 이번에 확인되지 않았다. Vercel 등 별도 위탁사가 있으면 업체·업무·국가·기간을 추가한다.
3. 기존 폼의 ‘알림 발송 후 즉시 파기’ 약속을 유지했다. 이 저장소에는 알림 발송 작업, 발송 완료 후 삭제 작업, 문의 메일함의 파기 자동화가 구현되어 있지 않다. 발송 운영 시 성공한 대상 삭제, 실패한 대상 재처리·정리, 철회 요청 처리 및 백업 파기를 운영 절차에 연결해야 한다. 이 작업은 해당 운영 절차를 구현했다고 주장하지 않는다.
4. 별도 출시 알림 발송업체를 연결하면 해당 위탁·국외이전 정보를 추가한다. 고객 문의용 Zoho가 출시 알림 발송에도 쓰인다고 가정하지 않았다.
5. 약관과 개인정보처리방침의 공개는 개인정보 동의, 수탁 계약 또는 보호 조치 이행을 대신하지 않는다. 현재 수집 폼에는 동의 거부 안내와 만 14세 이상 확인을 포함했다. 연령 확인은 자기 진술이며 신분증 수집이나 법정대리인 동의 시스템을 추가하지 않았다.
