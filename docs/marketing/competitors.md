# Petty 경쟁사 지도 (조사일: 2026-09-08)

Petty는 **AI 캐릭터 대화(AI character chat / roleplay)** 카테고리에 속한다. 아래는 웹 검색으로 확인한 경쟁 서비스 목록이며, 수치는 언론 보도·리뷰 매체 인용값이므로 배포 전 재확인이 필요하다. 출처는 문서 하단에 정리했다.

### 국내 시장에서 읽히는 것
- **제타의 독주**가 명확하고, "제타 대신", "제타 같은 앱", "제타랑 비슷한 앱"이 실제 검색·TikTok 탐색 쿼리로 존재한다. → Petty가 노려야 할 1순위 키워드군.
- 이탈 동기는 대체로 **대화 스타일 불일치 / 원하는 기능 부재 / 다른 경험에 대한 호기심**으로 보도된다. Petty의 "기억하고 이어지는 대화", "나만의 공간과 기록"이 여기에 정면으로 대응한다.
- 커뮤니티(아카라이브 `b/characterai`, DC 제타·AI채팅 갤러리, 나무위키 "Character.AI/대체 방안")가 실질적인 추천 경로다. 검색 결과 상단을 이들이 차지하므로, **웹 SEO만으로는 부족하고 커뮤니티 언급이 병행되어야 한다.**

## 4. Petty의 차별점 (비교 페이지 논지)

현재 랜딩 카피 기준으로 방어 가능한 주장:

1. **다국어** — 한국어·일본어·영어 동시 제공. 국내 경쟁사 중 가장 분명한 차별점이다. 제타만 일본 진출했고 크랙·버블챗은 한국어 전용
2. **나만의 공간과 기록** — 소중한 대화·순간을 기록하고 다시 열람
3. **기억하고 이어지는 대화** — 대화를 기억해 자연스럽게 이어감
4. **멀티플랫폼** — 웹(app.petty.im) + iOS + Android
5. **장르 폭** — 로맨스·현대·SF·판타지 (서하/이안/유리/카일/엘리아)

⚠️ **1·4번만 실제 차별점이다.** 2·3번은 경쟁사도 한다:

- **대화 기억은 차별점이 아니다.** 크랙은 "캐릭터가 지난 대화를 기억하고 먼저 메시지를 보낸다"를 서비스 특징으로 내세운다. 비교 문서에서 "우리만 기억한다"고 쓰면 그 자리에서 반박당한다.
- **멀티플랫폼도 대체로 패리티다.** 제타(zeta-ai.io), 크랙(crack.wrtn.ai), Character.AI 모두 웹+앱을 지원한다. 다만 "PC에서도 되나요" 류 검색 수요는 실재하므로 콘텐츠에서 다룰 가치는 있다.

⚠️ 여전히 검증 필요: 가격 정책, 무료 사용량 한도, 캐릭터 수, 창작자 수익 배분 여부. 비교 페이지에 쓰려면 **사실이어야** 하며, 추측으로 채우면 신뢰를 잃고 순위에도 해가 된다.
